# Weightless Gold

Gold no longer counts toward your carry weight. In the base game every coin weighs a little, so a big purse quietly fills your inventory (10,000 gold is 10 kg). With this mod it weighs nothing.

## Installation

1. Download the mod from [GitHub Releases](https://github.com/belakarkache/bg3-weightless-gold/releases).
2. In **BG3 Mod Manager**, import the `.pak`, enable **Weightless Gold** and click **Export Load Order to Game**.
3. Start the game. Gold now weighs 0.

## Known issues

- It overrides the shared `_Gold` stat, so it conflicts with any other mod that changes gold weight. Whichever loads last wins.
- Only gold. Coin pouches, gems and trade goods keep their normal weight.
- Not tested in multiplayer.
